# 🍓 KDT 1조 스마트팜 (Ddalgi Farm) Mobile App

> **스마트 농장 관제 및 로봇 원격 제어, AI 비전 병충해 진단 통합 앱**
>
> Flutter 프레임워크를 기반으로 MQTT 초저지연 통신과 AI 데이터 분석 기술을 결합한 차세대 스마트팜 관리 솔루션입니다. 정밀한 환경 모니터링부터 자율주행 로봇 제어까지 하나의 앱으로 통합 관리합니다.

---

## 📌 주요 기능 (Key Features)

### 1. 📊 통합 모니터링 및 AI 생육 분석
스마트팜 내부의 환경 변화를 정밀하게 추적하고, AI 데이터를 바탕으로 작물의 생육 상태를 분석하여 제공합니다.
*   **고정형 듀얼 Y축 차트**: 가로 스크롤 시에도 화면 양 끝에 습도(%)와 온도(°C) 축이 상시 고정되어, 방대한 양의 데이터를 조회할 때도 직관적이고 정밀한 수치 판독이 가능합니다.
*   **작물별 생육 비율 분석**: 등록된 작물의 상태를 '미숙', '적숙', '과숙' 3단계로 분류하고, AI가 진단한 수확 적기 예측 데이터를 바 차트(Bar Chart) 형태로 시각화합니다.
*   **커스텀 작물 관리 시스템**: 대시보드에 표시되는 작물의 이름과 대표 이모지(아이콘)를 자신의 농장 환경에 맞게 자유롭게 수정하고 기기에 영구 저장할 수 있습니다.

### 2. 🚨 실시간 병충해 알림 및 이력 관리
작물에 발생하는 병충해나 이상 증상을 즉각적으로 감지하고, 사용자가 놓치지 않도록 체계적인 알림을 제공합니다.
*   **MQTT 기반 실시간 경고**: 초저지연 프로토콜(MQTT)을 활용하여 서버의 AI 비전 진단 결과를 앱 내에서 실시간으로 수신합니다.
*   **지능형 알림 뱃지 동기화**: 읽지 않은 알림 개수를 계산하여 하단 내비게이션 및 대시보드 아이콘에 실시간으로 연동(99+ 등)합니다.
*   **상세 진단 팝업 및 사진 뷰어**: 발생 구역, 일시, 건강 상태 및 S3 기반 실시간 촬영 이미지를 고해상도 다이얼로그 형태로 제공합니다.

### 3. 🤖 자율주행 로봇 원격 제어
농장을 순찰하는 자율주행 로봇의 위치를 파악하고 원격으로 제어할 수 있는 직관적인 인터페이스를 제공합니다.
*   **안전망이 적용된 제어 패널**: 오터치 방지를 위한 '스냅 애니메이션' 슬라이더를 도입하여, 의도적인 조작 시에만 '순찰' 및 '정지' 명령이 전송됩니다.
*   **실시간 위치 트래킹 매핑**: 로봇의 현재 구역(Zone) 위치를 파악하여 앱 내 U자 형태 경로 맵 위젯에 실시간으로 시각화합니다.
*   **제어 기록 스마트 변환**: 백엔드 명령어를 사용자 친화적인 한글('동작', '정지', '귀환')로 자동 변환하여 가독성 높은 이력을 제공합니다.

### 4. 📅 스마트 영농 캘린더 및 계정 관리
농장의 주요 이벤트와 환경 상태를 캘린더 형태로 한눈에 관리하고 안전한 앱 사용 환경을 구축합니다.
*   **다차원 시각적 캘린더**: 날짜별 칸에 고온/고습(↑), 저온/저습(↓) 상태를 기호로 표시하고, 질병(🟡) 및 수확 예정일(🟠) 여부를 색상 점으로 압축 표현합니다.
*   **스마트 농장 메모장**: 특정 날짜에 최대 8자의 메모를 작성할 수 있으며, 렌더링 충돌 방지 로직을 적용하여 안전한 데이터 저장을 보장합니다.
*   **안전한 세션 및 리소스 관리**: 로그아웃 시 실시간 MQTT 소켓 통신을 완벽하게 해제하여 디바이스의 네트워크 및 배터리 리소스 누수를 차단합니다.

```text
lib/
├── core/
│   ├── app_constants.dart          # 전역 상수 (임계값, 스케일링, 타이머 등)
│   ├── api_config.dart             # 서버 및 MQTT 네트워크 설정

├── controllers/
│   └── controller_fruit_dashboard.dart # 대시보드 전용 UI 인터랙션 컨트롤러
├── widgets/
│   ├── common/                     # Scaffold, Button 등 재사용 공통 위젯
│   ├── calendar/                   # 캘린더 전용 타일 및 범례 위젯

└── main.dart                       # 앱 엔트리 포인트 및 Provider 주입
```

## 📄 핵심 최적화 기술 (Architecture & Optimization)

1.  **렌더링 엔진 안정화 (Anti-Crash)**
    *   다이얼로그 종료와 상태 갱신의 충돌을 막기 위해 `addPostFrameCallback`을 적용하여 `child._parent == this` 에러를 원천 차단했습니다.
2.  **데이터 조회 가속 (Pre-indexing)**
    *   캘린더 빌드 시 리스트 전체 탐색을 제거하고 $O(1)$ 복잡도의 **전역 맵(Map) 인덱싱**을 구현하여 즉각적인 터치 반응성을 확보했습니다.
3.  **실시간 통신 최적화 (Throttling)**
    *   쏟아지는 MQTT 데이터 폭주에 대응하여 **0.5초 간격의 UI 쓰로틀링**을 적용, 불필요한 리빌드를 방지하고 저사양 기기 성능을 보장했습니다.
4.  **메모리 관리 (Memory Capping)**
    *   실시간 로그 리스트를 최대 100개로 유지하는 캡핑 시스템을 도입하여 장시간 구동 시에도 일정한 메모리 점유율을 유지합니다.
