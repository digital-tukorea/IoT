# AI 기반 농원 순찰 및 관리 로봇

프로젝트 목표

농업 현장의 숙련 인력 부족 및 고령화, 인건비 증가 문제를 해결하기 위해 고안된 'AI 기반 농원 순찰 및 관리 로봇' 통합 시스템입니다.
반복적인 농원 순찰 및 작물 확인 업무를 로봇으로 자동화하고, AI와 IoT 기술을 활용해 작물 상태를 실시간으로 분석하여 노동력 절감과 농장 관리 효율 향상을 목표로 합니다.

## 기술 스택

Hardware: Arduino, Raspberry Pi, 웹캠 
AI / Vision: Python, YOLO (Google Colab GPU 학습 환경)
Backend Server: Python, FastAPI, MariaDB, AWS S3
Frontend (App): Android, Flutter
Communication: MQTT (Mosquitto), REST API (HTTP)

## 시스템 아키텍처

본 프로젝트는 앱(App), 서버(Server), 로봇(Robot), AI가 유기적으로 연결된 통합 시스템입니다.
명령 전달: 사용자가 앱에서 로봇 동작(순찰) 명령을 내리면 MQTT 통신을 통해 서버를 거쳐 로봇으로 전달됩니다.
자율 주행 및 수집: 로봇은 명령 기반으로 자율 주행하며 작물 이미지와 환경 데이터(온습도)를 수집합니다.
데이터 분석: 수집된 이미지는 라즈베리파이 내의 YOLO 모델과 색상 분석 알고리즘을 통해 분석됩니다.
결과 전송 및 저장: 분석된 작물 개수, 상태 결과 및 캡처 이미지는 서버로 전송되어 MariaDB 및 AWS S3에 저장됩니다.
모니터링: 최종적으로 농장 상태와 순찰 기록이 앱에 연동되어 실시간 모니터링이 가능합니다.

## 주요 기능 및 파트별 상세

1. 순찰 로봇
    명령 기반 자율 주행: 앱의 명령에 따라 출발, 정지가 가능하며 설정된 순찰 경로를 주행합니다.
    마커 인식 로직: 바닥의 마커를 센서로 인식하여 지정된 위치에서 정지하고, 캡처를 수행한 뒤 시작 지점으로 복귀합니다.
    비동기 처리 최적화: 라즈베리파이 내에서 AI 추론 및 데이터 업로드(HTTP) 작업을 백그라운드 스레드로 분리(비동기 처리)하였습니다.

2. AI 비전 및 상태 진단
    4종 작물 탐지: 가지, 포도, 딸기, 참외 클래스를 탐지하도록 YOLO 모델을 학습시켰습니다.
    3단계 하이브리드 건강 판단 시스템:YOLO 탐지: 작물의 종류와 위치를 탐지합니다.
    색상 분석 (HSV): 이상 색상 비율을 계산하여 1차적으로 병해충 여부를 판단합니다.
    외부 API 연동: 이상이 의심되는 경우에만 정밀 진단를 호출하여 구체적인 병명을 도출하여 연산 부하를 줄였습니다.

3. 백엔드 서버
    API 및 DB 관리: 회원, 작물, 로봇의 데이터를 처리하는 API를 구현하였으며, MariaDB를 기반으로 순찰 및 AI 진단 기록을 통합 관리합니다.
    데이터 무결성 확보: 로봇이 전송한 데이터 수신 시, 기존 작물 식별자(batch_id)를 대조하여 기존 데이터가 있으면 최신 생육 상태로 덮어쓰는(Upsert) 로직을 적용했습니다.
    MQTT 통신 중계: 앱의 제어 명령을 로봇에 전달하고, 센서 및 탐지 결과를 수신하는 양방향 브로커 역할을 수행합니다.

4. 사용자 애플리케이션
    원격 제어 패널: 사용자가 농원에 직접 가지 않고도 로봇의 순찰 시작 및 정지 명령을 내릴 수 있습니다.
    대시보드 모니터링: 선택한 작물의 상태와 환경 정보를 시각화된 차트와 함께 실시간으로 확인합니다.
    AI 진단 기록 조회: AI가 분석한 작물 진단 결과 이력을 앱 내에서 손쉽게 조회할 수 있습니다.

## AI 모델 성능 및 학습 특징
    데이터셋 구성: 총 8,151장의 데이터를 사용했으며, 오탐을 줄이기 위해 전체 데이터의 10%를 '작물이 없는 배경 이미지'로 구성하여 학습시켰습니다.
    학습 기법: 데이터 다양성 확보를 위해 Mosaic + Mixup 증강 기법을 사용하였고, 난이도를 단계별로 조절하는 커리큘럼 러닝을 적용했습니다.
    성능 지표: 딸기 클래스 등에서 높은 분류 성능을 보이며, Precision 94%, Recall 88%, mAP@50 94% 의 우수한 객체 탐지 정확도를 달성했습니다.
